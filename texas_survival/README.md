# Texas Survival

A terminal-based survival game set in Texas during an unexplained, prolonged power and internet outage. Inspired by The Last of Us, A Quiet Place, I Am Legend, 28 Days Later, Zombieland, and the classic Oregon Trail, but without zombies.

- Start in New Braunfels after 3 days of total outage
- Travel: Austin, Houston, Schulenburg (family property with an acre and a small fish pond)
- Hunt, fish, scavenge, and manage water, food, ammo, fuel, health, stamina, and morale
- Listen to radio for evolving narrative amidst uncertainty

## Run

```bash
python3 main.py
```

## Demo Mode (non-interactive)

Run a short automated sequence (useful for verifying it starts):

```bash
python3 main.py --demo
```

## Notes
- This is a single-player, text-based game. No external dependencies required.
- Save/load may be added later; right now it focuses on immersion, tension, and meaningful choices.
